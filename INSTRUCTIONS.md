# Инструкция по эксплуатации бота-модератора

## Что делает бот

Бот следит за разделами (темами) супергруппы. Для каждого раздела ты сам
решаешь, какие типы контента разрешены — можно разрешить только фото,
только видео, фото+видео+ссылки, вообще ничего кроме конкретного эмодзи,
или включить "ультра"-режим, где писать может только админ. Всё это
настраивается командами прямо в чате, без правки кода.

Есть предохранитель: пока не введёшь `/start`, бот вообще ничего не
удаляет, даже в зарегистрированных разделах.

---

## Типы контента

| Тип | Что это |
|---|---|
| `photo` | Фото |
| `video` | Видео |
| `gif` | Анимация/гифка |
| `text` | Обычный текст (без ссылки) |
| `link` | Сообщение содержит ссылку (обычную или гиперссылку в тексте) |
| `sticker` | Стикер (любой) |
| `voice` | Голосовое сообщение |
| `document` | Файл/документ |
| `dice` | Анимированный эмодзи: 🎰 🎲 🎯 🏀 ⚽ 🎳 |

Подпись (caption) к фото/видео не считается отдельным "text" — она едет
вместе с медиа и не мешает, если медиа разрешено.

## Команды

### Глобальные (в любом месте группы)

| Команда | Кто может | Что делает |
|---|---|---|
| `/start` | Админ | Включает модерацию во всех зарегистрированных разделах |
| `/stop` | Админ | Полностью выключает модерацию (предохранитель) |
| `/status` | Любой | Внутри раздела — показывает его настройки. Вне раздела — общий статус |
| `/sections` | Любой | Список всех зарегистрированных разделов и их правил |
| `/types` | Любой | Список всех доступных типов контента |

### Настройка раздела

Эти команды можно писать **внутри самого раздела** (тогда название в
конце указывать не нужно — бот и так поймёт, о каком разделе речь) —
**или из любой другой темы** (например из отдельной служебной темы
"Модерация"), указав название раздела последним аргументом.

| Команда | Кто может | Что делает |
|---|---|---|
| `/register <название>` | Админ | Регистрирует **текущий** раздел под модерацию (только изнутри самого раздела — иначе бот не узнает его id) |
| `/unregister [раздел]` | Админ | Снимает раздел с модерации, удаляет его настройки |
| `/section_on [раздел]` | Админ | Включает модерацию раздела |
| `/section_off [раздел]` | Админ | Выключает модерацию раздела |
| `/allow <тип> [раздел]` | Админ | Разрешает тип контента (например `/allow text Мемы`) |
| `/deny <тип> [раздел]` | Админ | Запрещает тип контента |
| `/adminonly_on [раздел]` | Админ | Ультра-режим: писать может только админ |
| `/adminonly_off [раздел]` | Админ | Выключает ультра-режим |
| `/allow_dice <эмодзи> [раздел]` | Админ | Разрешает конкретный dice-эмодзи (например `/allow_dice 🎰 Слоты`) |
| `/deny_dice <эмодзи> [раздел]` | Админ | Убирает эмодзи из списка разрешённых |

### Мьют отдельных пользователей

Действует **на всю группу сразу**, во всех разделах (даже незарегистрированных) —
это не настройка раздела, а бан конкретного человека на уровне всей группы.

| Команда | Кто может | Что делает |
|---|---|---|
| `/mute` (ответом на сообщение) | Админ | Мьютит автора сообщения, на которое ответили |
| `/mute @username` | Админ | Мьютит по юзернейму (если он публичный) |
| `/mute <user_id>` | Админ | Мьютит по числовому ID |
| `/unmute` (аналогично /mute) | Админ | Снимает мьют |
| `/muted` | Любой | Список всех замьюченных в этой группе |

Замьюченному человеку удаляются вообще все его сообщения, в любом разделе,
пока не выполнить `/unmute`. Админа замьютить нельзя. Самый надёжный способ
указать пользователя — **ответить командой на его сообщение** (юзернейм
резолвится через Telegram и работает не всегда, например если у человека
нет публичного @username).

### Чёрный список слов

Один общий список на весь бот. В отличие от остальной модерации, работает
**во всей группе сразу, в любом разделе** — даже незарегистрированном через
`/register`. Достаточно, чтобы была включена глобальная модерация (`/start`).
Проверяется и обычный текст, и подпись к фото/видео.

| Команда | Кто может | Что делает |
|---|---|---|
| `/blacklist_add <слово>` | Админ | Добавляет слово в чёрный список |
| `/blacklist_remove <слово>` | Админ | Убирает слово из чёрного списка |
| `/blacklist` | Любой | Показывает весь текущий список |

При срабатывании бот удаляет сообщение и пишет в тот же раздел:
*"Сообщение удалено. Причина: запрещённое слово «слово»"*.

### Антифлуд

Общий на весь бот (как мьют и чёрный список — работает в любом разделе,
зарегистрирован он или нет). **Админов не касается вообще.**

Логика: срабатывает от любого из трёх признаков —
1. Слишком много сообщений подряд за короткое время
2. 3+ одинаковых сообщения подряд (например, спам одним и тем же текстом)
3. 3+ сообщения подряд с упоминанием одного и того же `@username`

1-е и 2-е срабатывание — предупреждение (сообщение удаляется, в чат пишется
"предупреждение X/3"). 3-е — автоматический мут на настраиваемое время.
**После мута счётчик предупреждений обнуляется** — следующее нарушение
снова начинается с первого предупреждения, а не с мгновенного мута.
Мут временный и снимается сам по истечении времени.

| Команда | Кто может | Что делает |
|---|---|---|
| `/flood_on` | Админ | Включает антифлуд |
| `/flood_off` | Админ | Выключает антифлуд |
| `/flood_mute_time <минуты>` | Админ | Задаёт длительность мута после N-го предупреждения |
| `/flood_warn_count <число>` | Админ | Задаёт, сколько предупреждений даётся перед мутом (по умолчанию 3) |
| `/flood_status` | Любой | Показывает текущие настройки антифлуда |
| `/flood_reset` (ответом на сообщение или `@username`/id) | Админ | Сбрасывает счётчик предупреждений пользователю |

### Пресеты сценариев

Именованный снимок всех настроек модерации разом: какие разделы
зарегистрированы и что в них разрешено, чёрный список слов, настройки
антифлуда и включена ли модерация в принципе. Сохранил один раз —
дальше применяется одной командой вместо повторного набора всех команд
настройки. Хранится в том же Redis, что и текущие настройки — переживает
рестарт сервиса на Render сам по себе, никаких дополнительных действий
после рестарта не нужно.

| Команда | Кто может | Что делает |
|---|---|---|
| `/preset_save <название>` | Админ | Сохраняет текущие настройки под этим именем |
| `/preset_load <название>` | Админ | Заменяет текущие настройки на сохранённые в пресете |
| `/presets` | Любой | Показывает список сохранённых пресетов |
| `/preset_delete <название>` | Админ | Удаляет пресет |

Пример: настроил разделы и антифлуд под обычный день →
`/preset_save обычный`. Для вечеринки временно ослабил правила →
настроил заново → `/preset_save вечеринка`. Переключение между ними
одной командой: `/preset_load обычный` или `/preset_load вечеринка`.

### ИИ-разговор через упоминание

Если написать в чате `@имя_бота <вопрос>`, бот отправит текст после
упоминания в Google Gemini и ответит прямо в тот же чат/раздел. Не
завязано на модерацию — работает независимо от того, включена она
(`/start`) или нет.

Нужен ключ `GEMINI_API_KEY` в переменных окружения (`.env` локально,
Environment на Render). Без ключа бот ответит, что ИИ не настроен,
вместо того чтобы падать.

**Характер (по умолчанию):** отвечает от лица властной женщины-админа
с большим стажем модерации — строго, уверенно, без заискивания.

| Команда | Кто может | Что делает |
|---|---|---|
| `/ai_persona <описание>` | Админ | Меняет характер, которым отвечает ИИ |
| `/ai_persona_show` | Любой | Показывает текущее описание характера |

### Служебные

| Команда | Что делает |
|---|---|
| `/id` | Показывает thread_id текущего раздела |
| `/ids` | Ответом (reply) на сообщение со стикером — его file_unique_id |

## Примеры настройки

**Мемы — только фото, видео и ссылки:**
```
/register Мемы
/allow photo
/allow video
/allow link
```

**Слоты — только конкретный эмодзи 🎰:**
```
/register Слоты
/allow_dice 🎰
```

**Гартик — только фото и гифки:**
```
/register Гартик
/allow photo
/allow gif
```

**Чат — не регистрировать вообще**, тогда бот его не тронет в принципе
(даже без отдельной команды "не трогать" — незарегистрированные разделы
бот не проверяет).

**Раздел, где может писать только админ (объявления и т.п.):**
```
/register Объявления
/adminonly_on
```

**Удалённое управление из отдельной темы "Модерация":**
Зарегистрировать раздел всё равно нужно изнутри него самого (один раз),
а вот дальше настраивать можно из специально созданной темы, например
"Модерация", просто дописывая название раздела в конце команды:
```
/allow text Мемы
/deny video Гартик
/adminonly_on Объявления
/section_off Слоты
```
Удобно, когда не хочется заходить в каждый раздел по отдельности, а все
настройки держать в одном месте.

**Чёрный список слов (работает сразу во всех разделах):**
```
/blacklist_add реклама
/blacklist_add спам
/blacklist
```

---

`/stop` — глобально выключает модерацию во всех разделах сразу, не
трогая сами настройки (разделы, типы, ультра-режим). При следующем
`/start` всё вернётся как было.

## Как проверить текущие настройки

- `/status` внутри раздела — покажет именно его правила
- `/sections` — общий список всех разделов сразу

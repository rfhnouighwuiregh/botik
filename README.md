# Бот-модератор с гибкой настройкой разделов

## Файлы
- `bot.py` — основной файл, запускается
- `rules.py` — движок определения типа контента и проверки правил
- `state.py` — хранение настроек (в файле `state.json`, создаётся автоматически)
- `requirements.txt` — зависимости

Никакого `config.py` больше нет — всё настраивается командами прямо в группе.

## Установка
```
pip install -r requirements.txt
```

## Быстрый старт
1. Скопируй `.env.example` в `.env` и впиши туда свой токен от @BotFather (`BOT_TOKEN=...`)
2. У @BotFather выключи Group Privacy (Privacy Mode → Off)
3. Добавь бота в группу и сделай администратором с правом удаления сообщений
4. Запусти: `python bot.py`
5. Зайди в раздел, который нужно модерировать, и зарегистрируй его:
   `/register Мемы`
6. Разреши нужные типы контента: `/allow photo`, `/allow video`, `/allow link`
7. Включи модерацию глобально: `/start`

Полный список команд — в `INSTRUCTIONS.md`.
